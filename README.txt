Mobile and tablet support
- Refined phone and tablet workspace with a compact command header plus Preview, Timeline, Edit, and Project navigation.
- Portrait and landscape layouts, safe-area support, and touch-sized controls.
- One-finger clip movement, cross-layer dragging, trim handles, playhead scrubbing, and privacy-region drawing.
- Swipe the timeline to pan; use the dedicated mobile timeline strip for layer controls, Split, Magnet, Zoom, and Fit.
- Use Multi-select and Clip Actions for operations that normally require Shift-click or right-click on desktop.
- Project save/load remains in the Project drawer; Import, playback, Undo, and Export are always reachable from the compact mobile command header.
- Export As is fully responsive on phones and tablets. Video/audio formats depend on the specific browser; the startup compatibility panel and Export As dialog report actual availability.

What it does
- Upload video, image, and audio files locally.
- Assign them to stacked timeline layers.
- Toggle each layer visible/hidden.
- Drag clips in time and between layers.
- Resize clip duration from the left or right edge.
- Preview composited visible image/video layers.
- Play synced audio/video along the timeline.
- Save and load projects as .layercut files.
- Export video in browser-supported MOV, MP4, or WebM containers, with selectable range, resolution, frame rate, bitrate, audio, filename, and burned-in preview time.
- Export animated GIFs with range, size, FPS, palette, dithering, loop, and time-overlay controls.
- Export audio-only in uncompressed WAV or a dedicated browser-supported M4A workflow, plus WebM/Opus and Ogg/Opus where available.
- Export the current frame as PNG, JPEG, or WebP at 50%, 100%, or 200% project size.
- Add text clips over picture/video.
- Add privacy scrub regions to image/video clips.
- Add visual privacy scrub regions to selected image/video clips.

Privacy tools
1. Select an image or video clip.
2. Use Draw Region to draw a blur, pixelate, or black-bar region on the preview.
3. Use the Security Scrub controls to draw privacy regions on the selected image/video clip. These regions are burned into preview and all visual exports.

Notes
- Privacy scrub regions are burned into preview and export.
- MOV, MP4/WebM, and compressed-audio exports use the browser-native MediaRecorder and run in real time. WAV uses real-time PCM capture, while GIF uses the built-in frame encoder. Only genuinely available browser formats are offered.
- MOV is finalized with the genuine QuickTime `qt  ` container brand. M4A is finalized with the `M4A ` major brand. MOV, MP4, and M4A codecs remain browser-selected; AAC is used only when the browser exposes AAC recording.
- Export resolution can differ from the project canvas; text, masks, and pixel-based effects scale with the output.
- Browser autoplay rules may require a click on Play before media audio is allowed.
- Some video codecs may not decode in every browser.


UI SCALING
- Use the top-right settings cog on desktop or the bottom-right Settings tab on mobile to scale the Top Toolbar, Project/File window, Clip Editor, Preview, Preview Info, and Timeline independently from 50% to 150%.
- Scaling preferences persist locally in the browser. Preview scaling does not change export resolution, and Timeline scaling does not change clip timing.
